# CaffNap · 饮前决策体验版

以饮用决策为核心，帮助用户调整已有习惯；实际记录服务于后续决策。

## 本地体验

直接用浏览器打开 `index.html`，无需安装、构建、账号或服务器。图标和插图都随项目提供，页面不请求远程接口。

原 v1.2 保留在 `legacy/v1.2/index.html`，便于对照。旧版模型说明见 `docs/legacy-model.md`。

GitHub Pages 发布入口为 `https://eriolshen.github.io/caffnap/`，实际部署状态以仓库的 Actions 记录为准。

## GitHub Pages

更新 `main` 分支后，`.github/workflows/pages.yml` 自动运行测试、生成静态文件并部署。Pages 设置使用 GitHub Actions。也可以在 Actions 中手动运行 Publish GitHub Pages。

`node scripts/build-pages.mjs` 在 `dist/` 生成网页运行所需文件，不包含测试截图、浏览器缓存、工作文档或数据库源文件。生成的页面会为脚本、样式和插图添加内容版本标识，避免更新时混用旧资源。线上与本地文件页面的记录互不自动同步；需要迁移时先导出 JSON，再到新页面导入。

公开版本保留纳挼崩音黑标题字体。需要临时切换系统标题字体时，可以设置仓库变量 `PUBLISH_TITLE_FONT=false` 后重新部署；无需改变本地样式。

## 已实现

- 欢迎页直接提供饮用反应自测和功能导览：可先完成 5 题自测，再认识页面；也可先看功能或直接使用。未填自测的用户可从首页补做，日常记录保持独立。
- 今日首页：咖啡小睡、咖啡因摄入、预测结果、宵禁反推及三条曲线全部直接可见；绿色与咖啡棕双主色，代谢档案仅在设置页。
- 代谢档案以文字选项为主：默认估算、保守情景、已有基因报告。基因位点可选择或导入，不清楚可留空；直接填写数字放在折叠的高级参数中。
- 预测展示入睡时间估算、咖啡因达阈值时间、褪黑素节律推迟及小睡附加推迟。
- 咖啡因、褪黑素、清醒度曲线覆盖当日 06:00 至次日 12:00，标注目标、估算入睡和小睡时段。
- 小睡按日期保存；宵禁支持搜索饮品、调整分量，并累计已有摄入，不自动添加实际记录。
- 饮品搜索、品牌筛选、最近记录、自定义饮品。
- 想喝一杯：先选品牌和饮用时间、分量，按本次试算推荐同品牌饮品。结果优先显示相对“不加这一杯”预计延后多久，并提供入睡估算、降至参考浓度的时间和目标时刻残留。
- 试算当前分量、一半分量、同品牌较低咖啡因饮品、这次不喝；实际已喝直接添加，不必经过比较。
- 试算不写入实际记录；只有明确确认实际喝过才保存，拒绝未来时间。
- 记录新增、编辑、重复录入、删除与撤销；历史记录可编辑。
- 14 天回顾与可选睡眠反馈。反馈不会自动校准模型，没有连续打卡奖励。
- JSON 备份、旧版导入、重复导入去重，以及实际记录 CSV 导出。
- 保存失败提示、损坏数据保护、同浏览器多页面修改提示。

## 估算边界

使用原项目一级消除公式，多条实际记录按完整时间戳累计，支持跨午夜。图表与预测使用饮品区间中值；宵禁反推使用含量上限，扣除已有摄入在目标时刻的残留，再为额外一杯预留 30 分钟。截止时间已过、无追加余量、零咖啡因分别展示，不把过去的截止时间截断成 00:00。

参考阈值换算仍沿用 `remaining_mg / 42 × 1.15`。默认半衰期 4.5 小时、参考阈值 1 mg/L 是原模型假设，不是用户实测值。饮品含量范围只表示数据库含量范围，不是个体代谢或睡眠的置信区间。

饮前试算单独纳入计划中的未来饮品，不纳入实际记录中尚未发生的其他条目，也不写入存储。饮前入睡时间假设用户按目标时间上床，取睡眠目标与原模型预测时间的较晚者；额外延后与相同档案、小睡和既有摄入下的“不加这一杯”比较。展示时间向上取整到 5 分钟，超过次日中午的预测范围明确显示无法估算。咖啡因降至参考浓度不是完全代谢或安全保证。同品牌排序先看能否在目标前满足模型条件（残留用含量上限），再按预计入睡时间及残留上限排序，不代表实时菜单或普适的健康推荐。

入睡预测、褪黑素、清醒度和小睡影响沿用旧版的探索性假设，不代表已经科学或临床验证，不能保证入睡时间。没有摄入记录时显示“待记录摄入”，曲线只展示无摄入假设下的基线。清醒度假设起床后持续清醒，只扣除设置的小睡，不模拟夜间睡眠恢复。模型采用固定晚间节律，不适用于轮班等特殊作息。

本次修正原实现的小时/分钟混用、傍晚剂量相位窗口和自然曲线偏移问题，并将时间轴延伸到次日；因此数值可能不同于旧版。晚间剂量相对 21:00（加生物钟偏移）的 -5 至 +2 小时窗口计算延迟，每 200 mg 对应 40 分钟，上限 180 分钟；小睡延迟仍使用原经验公式。预测搜索至次日中午，超过范围会显示暂无法估算。

旧版基因档案可导入作为探索性参数，包含 PER1 偏移；代谢档案默认不要求填写数字。保守情景采用较长半衰期和较低参考阈值，仅是试算假设，不等同于判断用户的真实代谢或基因型。高级参数中仍可手动编辑半衰期、参考阈值、生物钟偏移。旧版睡眠校准保留但不自动应用。吐槽分享卡和宵禁日历仍仅在旧版对照页保留。

## 饮用反应小档案

欢迎页第一屏提供可选的五题自测入口：饮用频率、通常时段、睡眠变化、身体感受、调整方向。首页为尚未填写的用户保留补做入口；日常记录的睡眠目标页及设置页也可进入。逐题选择，支持返回修改和不确定答案；仅在结果页确认后保存，取消或跳过不会覆盖已有档案。

自测可作为预测起点：自述偶尔或经常出现睡眠变化／身体不适时，建议现有保守情景（半衰期 7.5 小时、阈值 0.8 mg/L）；其余先用默认情景（4.5 小时、1 mg/L）。这是产品层面的试算选择，不是经验证的量表或代谢测定；频率、时段、目标不用于推断代谢，未注意到反应不触发“快速代谢”或更宽松阈值。

结果页明确显示建议原因和参数，“将这组参数用于预测”在默认／保守模式下预选，已有手动／基因档案时不预选。确认后同时保存回答和参数，并重算预测、宵禁及曲线；取消不修改数据，取消勾选仅保存回答，写入失败回滚两者。旧自测不会自动应用，可在设置中查看并确认建议。参数来源包含应用日期，保存后的参数是当时选择的快照，不是持续自动同步。

`reactionAssessment` 仍独立存储，包含问卷版本、回答编码和更新时间，随完整 JSON 备份导出；旧数据缺省为 `null`。导入时保留已有本机反应档案，仅在本机未填写时采用备份中的档案。

## 字体

标题使用用户提供的 `assets/NanoTikBazHei-Bold.ttf`（纳挼崩音黑），正文、数字与表单沿用系统字体。字体使用 `font-display: swap` 避免阻塞正文。项目维护者于 2026-11-12 确认该字体为开源免费字体、允许网页使用和公开分发；本次依据该确认随页面发布。原始字体许可证文件尚待补充归档。

## 功能导览

首次使用且尚未完成旧版引导的用户先看到欢迎介绍，可选择“先做个小自测”“先看看功能”或“先自己逛逛”。已有用户可通过首页“新手引导”重新进入，不需要清除记录。聚焦导览支持点击背景空白处继续，以及上一步、下一步、跳过与 Esc。

先做自测的用户，保存或跳过后可选择继续五步功能介绍，也可以直接开始使用；关闭自测则退出，不强行推进。先看功能的用户，完成后仍可选择自测；已经填写过、刚明确跳过自测或中途退出导览，不重复邀请。已有高级参数不会被跳过操作重置为默认，应用自测建议仍需要明确确认。首页补做自测完成后直接返回，不再要求看导览。导览和欢迎本身只保存 `featureTourSeen` 偏好，不修改健康档案或新增实际记录。

聚焦遮罩与切换使用固定版本 Driver.js 1.12.1，JS、CSS 和 MIT 许可证均本地提供。窄屏中无法同时容纳整个板块和说明时聚焦标题区；遵循 `prefers-reduced-motion` 关闭动画和平滑滚动。

## 数据与后续云端适配

v2 使用新键 `caffnap_workspace_v2`，首次读取时兼容 v1 本地记录，旧键不覆盖。旧记录中的演示数据与真实数据无法可靠区分，迁移保留原始内容，由用户检查。

实际记录具有稳定 ID、完整 ISO 时间戳、创建/修改时间、删除标记和饮品快照。饮品库变化或移除自定义饮品不会改写既有摄入剂量。

当前存储适配器是同步本地接口，不等于已实现云同步。接云端时需要增加异步仓储接口、认证、用户隔离、重试队列、同步冲突和迁移策略。小程序可以复用计算与数据结构，页面、文件、提醒及存储 API 需要单独适配。本版不包含账号、服务端或微信小程序工程。

本地文件与线上域名的存储互不等同。测试旧线上记录时，应先从原站导出，再在本版导入。
