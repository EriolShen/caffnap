- 问题原因：旧流程只在完成五步导览后邀请自测，跳过导览和已经关闭欢迎页的用户不容易找到它。

- 文案简化睡眠和身体反应问题，不改变答案编码、问卷映射或预测计算。缩小欢迎插画、调整双入口间距，保留原有字体与配色。
- 54 项单测覆盖原有计算、存储、自测、导览以及新增入口和返回逻辑。`tests/newcomer-checks.mjs` 覆盖问卷直达、键盘选择、上一步答案保留、存储失败重试、应用建议、跳过后不重复邀请、老用户补做及保留手动参数。
- 1440、390、320px 欢迎页自测按钮可见且无水平溢出；手机长题目、错误与完成画面见 `output/qa/newcomer-v2-*.png`。其余页面继续用原七种尺寸及曲线/记录/导览回归检查。
- 检查范围限于上述流程；没有进行 iOS、微信真机或真实读屏验证。预测科学性和数据云同步不在此次修改中。

## 既有限制

- 备份迁移与合并已经过自动测试；文件选择器、下载在各浏览器和微信环境中的行为尚未逐一验证。
- 本地 HTML 由构建方式支持；内置浏览器不接受 file 协议，因此交互验证通过仅提供本项目静态资源的临时本机 HTTP 服务完成。
- 这不是微信小程序实机验证，也没有云同步、账号、付费和通知测试。
- 字体文件来自用户提供的本地文件；附带目录无许可证正文，尚未核实公开分发授权，未部署。
- 模型恢复了原项目探索性的入睡、褪黑素、清醒度和小睡推迟估算；修正时间单位和跨天问题不等于验证医学准确性，没有临床或个体预测准确性验证。
- 新版与旧版使用不同本地存储键。旧版本继续录入的数据不会自动反向同步到已初始化的新版本，可手动导出再导入。
