# Better Interface 检查与修正

日期：2026-11-12。范围：首次进入与五步功能导览、首页、饮品搜索、比较、记录、删除和撤销、三张曲线；回顾和设置的一级页面。

技术栈：原生 HTML/CSS/JavaScript，原生 dialog、本地 Lucide 与 Driver.js。参考项目的 README、visual-direction.md、verification.md。保留纳挼崩音黑标题、系统内文、瓷白底、柔和绿与棕色强调、浅蓝灰睡眠区域，以及全部首页功能。

采用 better-interface 组织审查，并使用 better-accessibility、better-layout、better-writing、better-typography、better-colors、better-ui 的相关规则。没有改预测算法、自测参数映射、账户或云端架构。高级基因导入、备份恢复的浏览器流程不在本轮范围。

## 验证通过

- `node --test tests/*.test.cjs`：48 项通过；预测、存储、自测、导览及曲线原有测试未退化。
- `node --check app.js`、`git diff --check`：通过。
- `node tests/browser-visual.mjs`：隔离 Chrome profile 与 127.0.0.1 测试来源，不读写用户 file 页面记录。增加 `tests/interface-checks.mjs`，覆盖真实键盘事件、无障碍树、计算后样式与截图。
- 1440×900、1280×720、1024×768、820×1180、768×1024、390×844、320×740：首页无横向溢出，首屏主操作可见，两个主按钮不拆行，三张有纵轴标签的画布均非空。
- 三个一级页面通过 Enter 导航后，焦点和标题正确；检查到的按钮、输入、下拉和单选控件无缺失名称。页面普通文本最低对比度：首页约 4.64:1，回顾和设置约 5.03:1。该自动采样不覆盖浏览器原生控件内部文字及所有隐藏/高级状态。
- 弹窗键盘循环不进入背景应用。Chromium 允许在首尾之间经过浏览器自身界面，测试将此与错误进入背景控件区分。Escape 关闭后焦点返回打开按钮。
- 搜索无结果可用 Enter 清除筛选；返回比较前表单时焦点、标题正确；无效时间关联日期/时间字段；继续编辑清除旧错误。
- 删除 10.5 秒后仍能撤销；目标时间更新不覆盖撤销；连续删除两条能逐条恢复；手动关闭后保留删除，刷新仍正确。320px 下通知无横向溢出，测试中的曲线帮助焦点未被通知遮挡。
- 比较、保存、刷新、编辑入口、删除、曲线帮助焦点打开/Escape 关闭、五个手机导览步骤及完成邀请通过；五个提示均在视口内且不覆盖目标。
- 减少动态效果模拟下按钮过渡为 0 秒。以 720×450 CSS 像素、DPR 2 模拟 1440×900 屏幕 200% 页面缩放后的布局，无横向溢出；不是 Safari 真机缩放或 200% 纯文本放大证明。
- 图片与证据：`output/qa/interface-before.json`、`interface-after.json`、`interface-after-empty.png`、`interface-after-error.png`、`interface-undo-mobile.png`、`interface-curves-desktop.png`、`interface-curve-viewport-1.png` 至 `3.png`。长区域截图仅用于曲线观察，固定元素的位置以真实视口截图及边界断言为准。

## Not Verified

- VoiceOver/NVDA 的实际播报、Safari/iOS/微信真机、软件键盘遮挡、系统高对比模式、200% 纯文本放大、RTL 和长语言翻译。
- 高级基因文件、备份导入导出及跨标签并发撤销的完整浏览器流程。既有数据单测不替代这些实机验证。
- 医学准确性、云端、账号、商业化、字体公开分发许可与部署。本轮没有改变或验证这些事项。
- 没有重跑上一轮 design-taste 的营销模板检查或性能检测。其 `FAIL 30` 和字体/插画体积待优化记录仍有效，不被本报告覆盖。
